# TOP WIN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** TikTok names throughout overlays, draggable course and TOP WIN in game, always-on private link publication, weekly per-channel wins.
**Architecture:** Extend trusted Roblox map publisher and existing Node/SQLite Worker. Server emits an explicit once-per-race first-finish receipt; Worker stores receipts and weekly totals transactionally and returns the same board to web and game.
**Tech Stack:** Luau, Roblox UI, existing Node24 HTTP/SQLite, canvas/CSS.
**Spec:** docs/superpowers/specs/2026-10-18-weekly-overlays-design.md

## Global Constraints

- TOP WIN is the user-facing name.
- Per channel; Monday 00:00 Asia/Bangkok; top ten; stable actor identity.
- Filter external names before Roblox display. No client authority for results or channel identity.
- Preserve old private links, scoped credentials and current Studio edits.
- User deploys VPS and publishes game.

## Review Focus

- Retry after week rollover must count in finish week's bucket.
- A second or different winner packet for the same race never adds another win.
- Channels/universes cannot share scores accidentally.
- No racers, DNF, tests and offline state have truthful empty displays.
- Dragged widgets remain reachable after viewport resize.
